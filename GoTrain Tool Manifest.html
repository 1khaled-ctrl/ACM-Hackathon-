Tool Manifest

Every tool wired into the GoTrain training agent, in the order it moves through them — from first look at a dataset to a submitted model. 28 tools, six stages, one deliberately withheld.

  • Runtime  strands-agents 1.63.0
  • Limits  max runs / time / tool-calls enforced in code
  • Logging  every call → logs/events.jsonl
01 Dataset Intake 4 tools
list_datasets()

Lists the GEO-Bench dataset names available locally.

get_dataset_info(dataset)

Split sizes, band names, image shape, label/class info.

check_dataset_support(dataset)

Checks training/eval code support for one dataset without downloading it.

report_all_datasets()

Runs that support check across all 12 hackathon datasets at once.

02 Data Quality 6 tools
run_geoguard(dataset, task_type)

Pre-training scan of the train split's pixel stats and sensor characteristics.

run_dataiq_structural_scan(…)

Flags corrupted files and exact duplicates — NaNs, saturation, bad labels.

run_dataiq_loss_scan(…, run_id)

Model-assisted scan using a checkpoint to flag suspicious, high-loss examples.

run_stresslab(…, run_id)

Re-evaluates a checkpoint on validation under a battery of input perturbations.

list_data_proposals(dataset?)

Lists pending sample-exclusion proposals raised by the scans above.

create_data_manifest(…)

Builds a training manifest that excludes the flagged samples.

03 Model Selection 3 tools
list_compatible_models(task_type, dataset?)

Candidate pretrained backbones/encoders from the curated model registry.

estimate_model_resources(model_id)

Rough, explicitly-labeled parameter-count and GPU estimate — never a measurement.

validate_model_compatibility(…)

Actually builds the model for the real band/class count and runs one forward pass.

04 Planning & Diagnostics 4 tools
get_training_diagnostics(dataset, run_id)

Deterministic read of a completed run's ledger entry and metrics — no inference.

get_resource_status(dataset)

Live run / tool-call / data-experiment budget counters.

estimate_run_cost(dataset, config)

Predicts GPU-minutes for a candidate config from this dataset's own run history.

recommend_experiments(dataset, run_id)

Ranked, single-variable suggestions for what to try next.

05 Training & Run Tracking 7 tools
launch_training(dataset, task_type, config)

Starts a run — hard-capped by run/time/tool-call limits enforced in code.

get_run_status(run_id)

Full ledger record: config, val_metric, decision, rationale, parent_id.

get_run_metrics(run_id)

Just the metrics: val_metric, delta_vs_parent, gpu_minutes.

query_history(dataset?)

Every past run — required reading before each launch_training call.

compare_runs(run_id_a, run_id_b)

Config diff and validation-metric delta between two runs.

record_decision(run_id, decision, rationale)

Marks a run kept, discarded, or pending.

record_adaptation(…)

Logs how the agent responded when a proposal was rejected or blocked.

06 Reporting & Finalization 4 tools
generate_goaudit_report(dataset)

Persists an engineering report: every kept/discarded decision and its rationale.

submit_final_model(dataset, run_id)

Records the agent's final choice in the ledger — evaluates nothing.

upload_to_s3(dataset, version)

Pushes a registered model version to S3, if a bucket is configured.

download_from_s3(dataset, version)

Pulls a model version's files back into the local registry.

Withheld
final_test_eval()

Not in the agent's tool list, on purpose. The agent may only ever see validation metrics — the test split is scored exactly once, by a human, via run_final_eval.py.
